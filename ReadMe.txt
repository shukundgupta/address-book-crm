========================================================================
             ADDRESS BOOK CRM - PROFESSIONAL DESKTOP EDITION
========================================================================

Welcome to the Address Book CRM, a high-performance, multi-tenant desktop 
application designed for modern offices. This CRM streamlines customer 
management and email marketing with a "Pro" touch.

------------------------------------------------------------------------
A to Z FEATURE LIST
------------------------------------------------------------------------

[A] AUTHENTICATION (SECURE & MULTI-TENANT)
    - Secure JWT-based login system.
    - Multi-company support: Each company sees only their own data.
    - Password encryption for maximum security.

[B] BACKEND ENGINE
    - Powered by Node.js and Express v5 for high performance.
    - Individualized company transporters for custom SMTP settings.

[C] CUSTOMER MANAGEMENT
    - Detailed profiles: Company Name, Contact Person, Email, Phone.
    - Geographic Data: State, City, and Pincode tracking.
    - Custom Tags: Categorize customers for targeted marketing.

[D] DESKTOP EXPERIENCE
    - Native Windows Application (.exe) for easy installation.
    - Professional Glassmorphism UI with smooth animations.
    - Zoom Controls: Ctrl + / - / 0 for accessibility.

[E] EMAIL CAMPAIGNS
    - Powerful HTML Composer: Create beautiful emails with ease.
    - Personalization: Auto-replace tags like {{company_name}} and 
      {{contact_person}} in every email.
    - Individual Sending: Sends 1-by-1 with 3s delay to prevent spam.

[F] FILTERING & SEGMENTATION
    - Granular filters: Filter by State, City, Pincode, or Tags.
    - Customer Types: Segregate "Existing" vs "New" leads.
    - Live Preview: See recipient counts before hitting send.

[G] GRAPHICAL TEMPLATES
    - Customizable Headers & Footers: Professional branding for every mail.
    - Accent Colors: Match your company's identity with custom theme colors.

[H] HISTORY & LOGS
    - Campaign History: Track every campaign sent in the past.
    - Real-time Logs: Detailed status for every recipient (Sent/Failed).
    - Error Tracking: View specific reasons for failed deliveries.

[I] INSTALLATION (SERVER/CLIENT ROLES)
    - Server Mode: Runs the database and acts as the central hub.
    - Client Mode: Connects to the Server PC over LAN.
    - Auto-IP Detection: Tells you exactly what IP to use for your network.

[J] JSON CONFIGURATION
    - Persistent settings stored in your AppData for reliable restarts.

[L] LAN CONNECTIVITY
    - Built-in support for office networks. Multiple staff can use the 
      CRM simultaneously.

[M] MEDIA & ATTACHMENTS
    - Upload multiple files (PDFs, Images) to send with your campaigns.
    - Persistent attachment storage for draft campaigns.

[N] NETWORK STATUS
    - Automatic connection testing between Client and Server PCs.
    - Built-in 45-second retry logic for network discovery.

[P] PREVIEW SYSTEM
    - Preview recipient lists before sending.
    - Estimated time calculations for large campaigns.

[R] RESET & MAINTENANCE
    - "Reset Application" feature to change Server/Client roles.
    - Integrated WAMP/MySQL verification.

[S] SOCIAL MEDIA INTEGRATION
    - Add Facebook, Instagram, LinkedIn, and Twitter links to email footers.
    - Icons are automatically styled in premium circular frames.

[T] TRACKING DASHBOARD
    - Live counters for "Sent", "Failed", and "Total" during campaigns.
    - Progress bars for background sending.

[U] UI DESIGN
    - Modern dark-theme aesthetic with "Inter" typography.
    - Responsive layout that adapts to your desktop resolution.

[W] WAMP INTEGRATION
    - Seamlessly communicates with WAMP for local database management.
    - One-click launch via the desktop shortcut.

------------------------------------------------------------------------
TECHNICAL SPECIFICATIONS
------------------------------------------------------------------------
- Frontend: Angular (v17+)
- Backend: Node.js / Express
- Database: MySQL (WAMP)
- Shell: Electron (Desktop Bridge)
- Packaging: Electron Builder (NSIS Installer)
